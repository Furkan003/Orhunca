# İlk program

> Ekrana yazı yazdırmak, metinler ve yorumlar.

Bilgisayara ne yapacağını Türkçe cümlelerle söyleriz. Ekrana bir şey yazdırmak için önce
yazdırılacak değeri, sonra **yaz** fiilini yazarız; cümle nokta ile biter:

```orhunca
"Merhaba, dünya!"'yı yaz.
```

```cikti
Merhaba, dünya!
```

Tırnak içindeki yazılara **metin** denir. Metinden sonra gelen ek (`'yı`) Türkçede olduğu
gibi kesme işaretiyle ayrılır. Ek, kelimenin son hecesine uyar: `"dünya"'yı`, `"Ali"'yi`,
`"okul"'u`, `"gül"'ü`. Yanlış ek yazarsanız program yine çalışır; Stüdyo doğrusunu önerir.

Her satır sırayla çalışır. `#` ile başlayan satırlar **yorumdur**; bilgisayar onları okumaz,
kodu okuyan insanlar için yazılır:

```orhunca
# Benim ilk programım
"Merhaba!"'yı yaz.
"Orhunca öğreniyorum."'u yaz.
```

```cikti
Merhaba!
Orhunca öğreniyorum.
```

Metinleri `+` ile birleştirebilirsiniz. Birleştirilmiş bir ifadeyi yazdırırken parantez
kullanın; ek parantezin tamamına aittir:

```orhunca
("Orhunca" + " " + "Stüdyo")'yu yaz.
```

```cikti
Orhunca Stüdyo
```

## Alıştırma: Kendini tanıt

Ekrana iki satır yazdıran bir program yazın: önce `Merhaba, ben Orhunca.`, sonra
`Programlamayı seviyorum.`

```orhunca baslangic
# İlk satırı yazdırın, sonra ikinciyi
```

```cikti
Merhaba, ben Orhunca.
Programlamayı seviyorum.
```

```orhunca cozum
"Merhaba, ben Orhunca."'yı yaz.
"Programlamayı seviyorum."'u yaz.
```
