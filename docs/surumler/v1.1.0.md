## Orhunca 1.1 — veritabanları, paketler ve Visual Studio gibi bir Stüdyo

1.0'da çalışan her program 1.1'de de aynen çalışır; bu sürüm yalnızca yeni şey ekler.
Kayıtlar varsayılan olarak yine `veri/` klasöründeki JSON dosyalarına yazılır.

### İndir

| Sistem | Dosya |
|---|---|
| Windows 10/11 | `Orhunca-Studyo-Windows-Kurulum.exe` (önerilen) ya da `Orhunca-Studyo-Windows.msi` (okul ağına toplu kurulum) |
| Pardus, Ubuntu, Debian | `orhunca-studyo_amd64.deb` |
| Fedora, openSUSE | `orhunca-studyo.x86_64.rpm` |
| Diğer Linux | `Orhunca-Studyo-Linux.AppImage` |
| Raspberry Pi 4/5, ARM Linux (64 bit) | `orhunca-linux-aarch64.tar.gz` ya da `kur.sh` (komut satırı) |
| macOS 10.15+ | `Orhunca-Studyo-macOS.dmg` (Intel ve Apple Silicon) |
| Yalnızca komut satırı | `orhunca-*.tar.gz` / `.zip`, ya da `kur.sh` / `kur.ps1` |

Kurulum `orhunca` komutunu da ekler ve `.ohc` dosyalarını Stüdyo'yla açar. Kurulum dosyaları
henüz kod imzalı değildir: Windows'ta "Bilinmeyen yayımcı" uyarısında *Ek bilgi → Yine de çalıştır*,
macOS'ta ilk açılışta *sağ tık → Aç* seçin. Uyarısız kurulum için paket yöneticileri:
`scoop bucket add orhunca https://github.com/Furkan003/Orhunca` (Windows),
`brew tap furkan003/orhunca https://github.com/Furkan003/Orhunca` (macOS, Linux). Her dosyanın bu
depoda derlendiği `gh attestation verify <dosya> --repo Furkan003/Orhunca` ile doğrulanır
(ayrıca `SHA256SUMS.txt`).

### 1.1'de neler var

- **Veritabanları:** `.env` dosyasına tek satır: `ORHUNCA_VERITABANI=sqlite`, `postgresql://…`,
  `mysql://…` (MariaDB de) ya da `sqlserver://…` (SSMS ile açılır). Modeller tablolara yazılır,
  eski JSON kayıtları bir kez içe aktarılır. `sql_sorgu` / `sql_çalıştır` ile doğrudan SQL.
  PHP çevirisi artık PostgreSQL'e de bağlanır.
- **Resmi paketler (15):** giriş (üyelik, şifre sıfırlama, API anahtarı), özet (SHA-256,
  PBKDF2), karekod, barkod, kimlik (UUID), günlük, grafik_svg, sayfala, insancıl, markdown,
  metin_araçları, doğrula_tr, sahte_veri ve diğerleri. `güvenli_anahtar(n)` yerleşiği.
- **Yeni şablonlar:** Yönetim Paneli, REST API + Giriş, Çözüm (web + mobil + ortak kod), Komut
  Satırı Aracı, Arka Plan İşi, Sınama Projesi.
- **Stüdyo:** veritabanı görüntüleyici ve SQL sorgusu, KABUK sekmesi (proje klasöründe komut
  satırı), Profil çıkar, çalışma alanında başlangıç projesi, eklentiler, `--uzak` ile SSH
  üzerinden uzaktan geliştirme.
- **Telefon:** `kamera`, `karekod_okuyucu`, `konum`, `dosya_seç` arayüz öğeleri (Android ve
  iPhone izinleriyle).
- **Web:** `js_çalıştır` / `js_yükle` ile JavaScript kütüphaneleri; tarayıcıda `bekle` artık
  sayfayı dondurmuyor.
- **Araçlar:** `orhunca profil` (işlev süreleri, sıcak satırlar), `orhunca erişilebilirlik`
  (açıklamasız resim, etiketsiz kutu, düşük karşıtlık).
- **Dil:** aynı adın farklı dosyalarda yerel olarak kullanılması artık çakışma sayılmıyor;
  `istek.oturum` yenilenince oturum kimliği de yenileniyor (oturum sabitleme saldırısına karşı).
