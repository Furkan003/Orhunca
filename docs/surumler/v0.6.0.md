## Orhunca 0.6 — okullar için ilk tam sürüm

Türkçe söz dizimiyle programlama: kurulum dosyaları, Stüdyo'da dersler, temalar, yapay zekâ
asistanı, otomatik güncelleme, yeni kütüphane ve arayüz öğeleri.

### İndir

| Sistem | Dosya |
|---|---|
| Windows 10/11 | `Orhunca-Studyo-Windows-Kurulum.exe` (önerilen) ya da `Orhunca-Studyo-Windows.msi` (okul ağına toplu kurulum) |
| Pardus, Ubuntu, Debian | `orhunca-studyo_amd64.deb` |
| Fedora, openSUSE | `orhunca-studyo.x86_64.rpm` |
| Diğer Linux | `Orhunca-Studyo-Linux.AppImage` |
| Raspberry Pi 4/5, ARM Linux (64 bit) | `orhunca-linux-aarch64.tar.gz` ya da `kur.sh` (komut satırı) |
| macOS 10.15+ | `Orhunca-Studyo-macOS.dmg` (Intel ve Apple Silicon) |
| Yalnızca komut satırı | `orhunca-*.tar.gz` / `.zip`, ya da `kur.sh` / `kur.ps1` |

Kurulum `orhunca` komutunu da ekler ve `.ohc` dosyalarını Stüdyo'yla açar. Kurulum dosyaları
henüz imzalı değildir: Windows'ta "Bilinmeyen yayımcı" uyarısında *Ek bilgi → Yine de çalıştır*,
macOS'ta ilk açılışta *sağ tık → Aç* seçin. Dosyaları `SHA256SUMS.txt` ile doğrulayabilirsiniz.

### Yenilikler

- **Yapay zekâ:** Stüdyo'da kendi Anthropic API anahtarınızla çalışan asistan. Kod yazar, yazdığı
  kodu denetleyip çalıştırır, değişikliği siz onaylarsınız. Claude Code, Cursor gibi ajanlar
  `orhunca mcp` ile bağlanabilir. Okullar `ORHUNCA_YAPAY_ZEKA=kapali` ile kapatabilir.
- **Temalar:** bütün renkler, yazı tipleri, ölçek; resim, GIF ya da video arka plan; `.ohctema`
  dosyasıyla dışa/içe aktarma ve topluluk galerisi.
- **Otomatik güncelleme:** Stüdyo yeni sürümü bildirir ve kurar; komut satırında `orhunca güncelle`.
  İndirilen dosya SHA-256 ile doğrulanır. Okullar `ORHUNCA_GUNCELLEME=kapali` ile kapatabilir.
- **ARM:** 64 bit ARM Linux (Raspberry Pi 4/5) desteği.
- **Dersler:** 13 Türkçe ders (ilk programdan web'e); Stüdyo'da alıştırmalar çalıştırılıp
  çıktıyla denetlenir. Dersler web sitesinde de okunur.
- **Tarayıcıda deneme:** kurulumsuz, paylaşılabilir bağlantılarla.
- **Stüdyo:** yeni logo ve açılış, açık tema, doğru hâl ekini öneren tamamlama, adım adım
  gösterim, klavye ve ekran okuyucu desteği.
- **Hata mesajları:** başka dillerden gelen alışkanlıklar (`print(...)`, `for`, `def` …) için
  Orhunca karşılığı; yanlış yazılmış isimlere "bunu mu demek istediniz?".
- **Kütüphane:** tarih hesapları, desenler (düzenli ifadeler), CSV, JSON, HTTP istekleri.
- **Arayüz öğeleri:** tablo, grafik (çubuk, çizgi, pasta), sekmeler, iletişim kutusu.
- **Paketler:** paket dizini (`orhunca paket ara`), resmi istatistik ve geometri paketleri.
- **`orhunca etkileşim`:** satır satır deneme ortamı.
- **Dayanıklılık:** sonsuz özyineleme yakalanabilir hata verir; derleyici aşırı girdide çökmez;
  web sunucusu ve Stüdyo için güvenlik düzeltmeleri.
