## Orhunca 0.11 — profesyonel geliştirme

Orhunca'ya büyük programlar için gereken araçlar geldi: sınamalar, Git, gelişmiş hata ayıklayıcı,
yeniden adlandırma. Dil model işlevleri, adsız işlevler ve `arka planda:` bloğuyla büyüdü.
Yalnızca PHP ve MySQL sunan barındırmalara da yayınlanabiliyor.

### İndir

| Sistem | Dosya |
|---|---|
| Windows 10/11 | `Orhunca-Studyo-Windows-Kurulum.exe` (önerilen) ya da `Orhunca-Studyo-Windows.msi` (okul ağına toplu kurulum) |
| Pardus, Ubuntu, Debian | `orhunca-studyo_amd64.deb` |
| Fedora, openSUSE | `orhunca-studyo.x86_64.rpm` |
| Diğer Linux | `Orhunca-Studyo-Linux.AppImage` |
| Raspberry Pi 4/5, ARM Linux (64 bit) | `orhunca-linux-aarch64.tar.gz` ya da `kur.sh` (komut satırı) |
| macOS 10.15+ | `Orhunca-Studyo-macOS.dmg` (Intel ve Apple Silicon) |
| Yalnızca komut satırı | `orhunca-*.tar.gz` / `.zip`, ya da `kur.sh` / `kur.ps1` |

Kurulum `orhunca` komutunu da ekler ve `.ohc` dosyalarını Stüdyo'yla açar. Kurulum dosyaları
henüz kod imzalı değildir: Windows'ta "Bilinmeyen yayımcı" uyarısında *Ek bilgi → Yine de çalıştır*,
macOS'ta ilk açılışta *sağ tık → Aç* seçin. Uyarısız kurulum için paket yöneticileri:
`scoop bucket add orhunca https://github.com/Furkan003/Orhunca` (Windows),
`brew tap furkan003/orhunca https://github.com/Furkan003/Orhunca` (macOS, Linux). Her dosyanın bu
depoda derlendiği `gh attestation verify <dosya> --repo Furkan003/Orhunca` ile doğrulanır
(ayrıca `SHA256SUMS.txt`).

### Dil

- **Model işlevleri:** modelin içinde `işlev özet() -> metin:` tanımlanır, alanlara `bu.ad` ile
  erişilir, `k.özet()` ile çağrılır. Python/JavaScript çevirisinde sınıfın yöntemleri olur.
- **Adsız işlevler:** `süz(notlar, işlev(n) -> n >= sınır)`, `dönüştür(...)`, `biri_mi(...)`,
  `hepsi_mi(...)` ve `sırala(kişiler, işlev(k) -> k.yaş)` (yerinde, kararlı, Türk alfabesine göre).
  Dışarıdaki değişkenler kullanılabilir.
- **Arka planda:** arayüz programlarında `arka planda:` bloğu ekran çizildikten sonra çalışır
  ("Hesaplanıyor…" görünür), `bitince:` bloğu sonucu yazar. Konsol ve sunucu programlarında sırayla
  çalışır.

### Araçlar

- **Sınamalar:** `doğrula(koşul)` ve `eşit_olmalı(gerçek, beklenen)`; `orhunca sına` sınama
  dosyalarını çalıştırır, Stüdyo'da Sınamalar paneli.
- **Git paneli:** değişiklikler, hazırlama, işleme, gönderme/çekme ve satır satır fark görünümü.
- **Gelişmiş hata ayıklayıcı:** koşullu kesme noktası, günlük noktası (durmadan yazar), izlenen
  ifadeler; VS Code ve diğer düzenleyiciler için `orhunca ayıkla-dap`.
- **Yeniden adlandırma ve başvurular:** F2 bir ismi bütün projede değiştirir, ⇧+F12 kullanıldığı
  yerleri listeler (Stüdyo ve dil sunucusu).
- **PHP'ye çevirme:** `orhunca yayınla --php` web programını PHP 8.1+'a çevirir; modeller MySQL'de
  (ya da SQLite'ta) saklanır. CGI'ye izin vermeyen barındırmalar için. Bkz.
  [yayınlama rehberi](https://github.com/Furkan003/Orhunca/blob/HEAD/docs/yayinlama.md#phpye-çevirmek).
- **Editör:** eşleşen parantez işaretlenir, parantez ve tırnaklar kendiliğinden kapanır,
  Alt+↑/↓ satırı taşır, Ctrl+G satıra gider. Stüdyo'nun kodu modüllere bölündü.
- VS Code eklentisi 0.7: yeni anahtar kelimelerin renklendirilmesi.

Gerçek cihazlarda denemek için: [docs/deneme-listesi.md](https://github.com/Furkan003/Orhunca/blob/HEAD/docs/deneme-listesi.md)
