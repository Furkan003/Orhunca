## Orhunca 1.2.0 — Stüdyo, Visual Studio gibi

Bu sürüm Stüdyo'ya Visual Studio ve VS Code'da alışılan dosya, gezinme ve proje araçlarını getiriyor.

### Dosyalar ve gezgin
- **Sağ tık menüsü:** yeni öğe, yeni dosya/klasör, kes, kopyala, yapıştır, çoğalt, yeniden adlandır (F2), sil (Delete), yolu kopyala, dosya gezgininde göster.
- **Sürükle-bırak** ile taşıma (Ctrl basılıysa kopyalama).
- **Yeni öğe ekle** (Ctrl+Shift+A): model (sınıf), seçenek, sınama, web yolu, görünüm, arayüz bileşeni, CSS, JavaScript, JSON, Markdown.
- Stüdyo dışında değişen dosyalar fark edilir: kaydedilmemiş değişiklik yoksa yeniden yüklenir, varsa sorulur.

### Düzenleyici ve gezinme
- **Dosyada bul / değiştir** (Ctrl+F / Ctrl+H, F3): büyük-küçük harf, tam kelime, düzenli ifade.
- **Tanıma git** (F12 ya da Ctrl+tıklama), geri dön (Alt+←).
- Kendi işlev, model ve değişkenlerinizin **üzerine gelince bilgi**; `işlev(` yazınca **parametre yardımı**.
- **Hızlı aç** (Ctrl+P), **komut paleti** (Ctrl+Shift+P ya da F1), `:12` ile satıra git.
- **Sekme menüsü:** diğerlerini / sağdakileri / tümünü kapat; kapanan sekmeyi geri aç (Ctrl+Shift+T).
- **Ekranı bölme** (Ctrl+\\): iki dosya yan yana.
- **Kod parçacıkları:** satır başında `işlev`, `eğer`, `her`, `model`, `al`, `sına`… yazıp Tab.
- **Yer imleri:** Ctrl+Alt+K ekle/kaldır, Ctrl+Alt+L / J sonraki/önceki.

### Proje, çalıştırma ve Git
- **Proje özellikleri** (Dosya menüsü): ad, sürüm, giriş dosyası, veritabanı.
- **Çalıştırma ayarları:** program argümanları ve ortam değişkenleri.
- **Düzenleyici ayarları:** girinti genişliği, kod yazı tipi, kaydederken biçimlendirme.
- **Git:** dal oluşturma, geçiş, birleştirme, silme; işlemeye tıklayınca değişiklikleri; imlecin satırını kimin, ne zaman değiştirdiği.

### Önizleme ve araçlar
- Resim önizleme (PNG, JPEG, GIF, WebP, SVG), Markdown önizleme, CSV ve JSON dosyalarını tablo olarak görme.
- Sorunlar panelinde süzgeç (hatalar / uyarılar / yalnızca açık dosya / metin).
- **YAPILACAKLAR** sekmesi: `# YAPILACAK:`, `# TODO:`, `# DÜZELT:` notları.
- **Birden çok kabuk** sekmesi.
- **İki dosyayı karşılaştırma** (gezginde sağ tık).
- **Sınama kapsamı:** Sınamalar panelinde *Kapsamı ölç* ya da `orhunca sına --kapsam`; çalışmayan satırlar düzenleyicide kırmızı işaretlenir.

### İndir

| Sistem | Dosya |

| Yalnızca komut satırı | `orhunca-*.tar.gz` / `.zip`, ya da `kur.sh` / `kur.ps1` |
