## Orhunca 0.7.2 — Windows düzeltmesi

### İndir

| Sistem | Dosya |
|---|---|
| Windows 10/11 | `Orhunca-Studyo-Windows-Kurulum.exe` (önerilen) ya da `Orhunca-Studyo-Windows.msi` (okul ağına toplu kurulum) |
| Pardus, Ubuntu, Debian | `orhunca-studyo_amd64.deb` |
| Fedora, openSUSE | `orhunca-studyo.x86_64.rpm` |
| Diğer Linux | `Orhunca-Studyo-Linux.AppImage` |
| Raspberry Pi 4/5, ARM Linux (64 bit) | `orhunca-linux-aarch64.tar.gz` ya da `kur.sh` (komut satırı) |
| macOS 10.15+ | `Orhunca-Studyo-macOS.dmg` (Intel ve Apple Silicon) |
| Yalnızca komut satırı | `orhunca-*.tar.gz` / `.zip`, ya da `kur.sh` / `kur.ps1` |

Kurulum `orhunca` komutunu da ekler ve `.ohc` dosyalarını Stüdyo'yla açar. Kurulum dosyaları
henüz imzalı değildir: Windows'ta "Bilinmeyen yayımcı" uyarısında *Ek bilgi → Yine de çalıştır*,
macOS'ta ilk açılışta *sağ tık → Aç* seçin. Dosyaları `SHA256SUMS.txt` ile doğrulayabilirsiniz.

### Düzeltmeler

- **Windows:** Stüdyo'da **Çalıştır**'a basınca açılan boş siyah konsol penceresi artık açılmıyor.
  Programın çıktısı Stüdyo'nun alt panelinde görünür. Derleme, asistan ve güncelleme sırasında
  anlık beliren pencereler de giderildi.

0.7.1'deki yenilikler (yapay zekâ için kısa rehber, yaklaşık beşte bir belirteç) bu sürümde de var.
