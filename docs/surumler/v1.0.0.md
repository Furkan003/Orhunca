## Orhunca 1.0 — ilk kararlı sürüm

Türkçe yazılan, Türkçe düşünen bir programlama dili artık kararlı. 1.0'da çalışan bir program,
1.x sürümlerinin hiçbirinde bozulmaz: dil (dil sürümü 1), komut satırı ve proje dosyası uyumlu
kalır. Ayrıntılar: [geriye uyumluluk](https://github.com/Furkan003/Orhunca/blob/HEAD/docs/uyumluluk.md).

### İndir

| Sistem | Dosya |
|---|---|
| Windows 10/11 | `Orhunca-Studyo-Windows-Kurulum.exe` (önerilen) ya da `Orhunca-Studyo-Windows.msi` (okul ağına toplu kurulum) |
| Pardus, Ubuntu, Debian | `orhunca-studyo_amd64.deb` |
| Fedora, openSUSE | `orhunca-studyo.x86_64.rpm` |
| Diğer Linux | `Orhunca-Studyo-Linux.AppImage` |
| Raspberry Pi 4/5, ARM Linux (64 bit) | `orhunca-linux-aarch64.tar.gz` ya da `kur.sh` (komut satırı) |
| macOS 10.15+ | `Orhunca-Studyo-macOS.dmg` (Intel ve Apple Silicon) |
| Yalnızca komut satırı | `orhunca-*.tar.gz` / `.zip`, ya da `kur.sh` / `kur.ps1` |

Kurulum `orhunca` komutunu da ekler ve `.ohc` dosyalarını Stüdyo'yla açar. Kurulum dosyaları
henüz kod imzalı değildir: Windows'ta "Bilinmeyen yayımcı" uyarısında *Ek bilgi → Yine de çalıştır*,
macOS'ta ilk açılışta *sağ tık → Aç* seçin. Uyarısız kurulum için paket yöneticileri:
`scoop bucket add orhunca https://github.com/Furkan003/Orhunca` (Windows),
`brew tap furkan003/orhunca https://github.com/Furkan003/Orhunca` (macOS, Linux). Her dosyanın bu
depoda derlendiği `gh attestation verify <dosya> --repo Furkan003/Orhunca` ile doğrulanır
(ayrıca `SHA256SUMS.txt`).

### 1.0'da neler var

- **Dil:** hâl ekleriyle Türkçe cümleler (`5'i sayılara ekle.`), kendi fiilleriniz, tip çıkarımı,
  modeller ve model işlevleri, seçenekler, adsız işlevler, hata yakalama, sınamalar.
- **Her yere:** Windows, Linux, macOS ve ARM için çalıştırılabilir dosya; tarayıcı (WebAssembly);
  masaüstü uygulaması; Android ve iOS; web sunucusu, VPS'e tek komutla yayın, paylaşımlı hosting
  (CGI) ve yalnızca PHP/MySQL sunan barındırmalar.
- **Orhunca Stüdyo:** Türkçe arayüz, canlı önizleme, hata ayıklayıcı, Git, sınamalar, yapay zekâ
  asistanı, dersler; telefonda ve tablette de çalışır.
- **Ekosistem:** paket mağazası (izinler ve içerik özetiyle), VS Code eklentisi ve dil sunucusu,
  Python/JavaScript karşılığını gösteren çevirici, yapay zekâ ajanları için MCP sunucusu.

0.11'den bu yana dilde değişiklik yok; 1.0 bir kararlılık sözüdür. Önceki sürümlerin yenilikleri
için [sürüm notları](https://github.com/Furkan003/Orhunca/tree/HEAD/docs/surumler).

Gerçek cihazlarda denemek için: [docs/deneme-listesi.md](https://github.com/Furkan003/Orhunca/blob/HEAD/docs/deneme-listesi.md)
